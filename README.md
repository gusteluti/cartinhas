# Entre Orbitas

Joguinho simples de nave para celular.

## Como jogar

- Abra `index.html` no navegador.
- Toque em **Comecar**.
- No celular, arraste o dedo pela tela para mover a nave.
- A nave atira sozinha para cima.
- No computador, tambem da para jogar com mouse ou setas.

## Como publicar

E um projeto estatico com apenas `index.html`.

Voce pode subir direto em GitHub Pages, Netlify, Vercel ou qualquer hospedagem de HTML.

## Ideia

Um arcade vertical com piadas leves e callbacks da conversa:

- Rotaract Aracoiaba da Serra e Rotaract Votura.
- Licitacao, edital, relatorio e prefeitura.
- Teste de software em maquinas agricolas.
- Danca, show de talentos, assobio, frio, jaqueta, cafe e 00:00.
- Pouca leitura: as referencias aparecem como frases curtas, inimigos e power-ups.
